## 关于我

曾任 AI 公司 CMO，现在经营营销工作室。我负责项目从策略、创意到执行与运营的主要工作，也持续尝试用 AI 让一个人能完成更多环节。

我关心的不是用了多少工具，而是：**做出来的东西有没有解决问题，营销有没有带来真实的顾客。**

## 我在做什么

| 方向 | 我的工作 |
| --- | --- |
| AI × 营销实战 | 用 AI 辅助分析顾客痛点与营销数据、构思广告和制作素材，再根据真实咨询与成交反馈调整 |
