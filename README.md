## 关于我

曾任 AI 公司 CMO，现在经营营销工作室。我负责项目从策略、创意到执行与运营的主要工作，也持续尝试用 AI 让一个人能完成更多环节。

我关心的不是用了多少工具，而是：**做出来的东西有没有解决问题，营销有没有带来真实的顾客。**

## 我在做什么

| 方向 | 我的工作 |
| --- | --- |
| 营销与广告 | 从顾客正在经历的问题出发，制定策略、制作创意，并根据咨询与成交反馈调整 |
| AI 工作流 | 用 AI 辅助分析、生成素材与制作流程，再由我判断和完成交付 |
| 网站与数据 | 搭建页面及广告来源追踪，让新顾客从哪里来变得更清楚 |
| 项目实验 | 构思想法、制作原型，探索 AI 如何帮助小团队完成更多工作 |
